# Spierings SK1265-AT6 — Blender 모델

조사한 구형 Spierings SK1265-AT6를 바탕으로 만든, 지브를 수평으로 펼친 외관 모델입니다. 단위는 미터입니다.

## 파일

- `spierings_sk1265_at6.blend`: 편집 가능한 모델, 재질, 조명, 카메라 3개.
- `spierings_sk1265_at6.glb`: 웹용 glTF 2.0 모델, 약 3.17MB. 촬영용 바닥·조명·카메라를 제외하고 크레인 부품과 재질만 포함합니다.
- `crane-overall.png`: 전체 3/4 시점.
- `crane-carrier-detail.png`: 차체·아웃리거·마스트 하부 확대.
- `crane-side.png`: 측면 정사영.
- `build_scene.py` 및 부품별 Python 모듈: Blender에서 다시 생성할 수 있는 소스.
- `verification.json`: 실제 Blender 장면에서 읽은 구조·치수 확인 결과.

## 웹에서 사용

`spierings_sk1265_at6.glb`를 웹 앱의 정적 파일 경로에 배치하고 Three.js의 `GLTFLoader` 등으로 불러옵니다. 외부 파일 참조가 없는 단일 파일이며, 미터 단위와 glTF의 Y축 위쪽 좌표계를 사용합니다. 조명과 카메라는 웹에서 설정합니다.

내보낸 파일의 형식과 부품 1,075개, 재질 10개가 포함된 것을 확인했습니다. 개별 부품 이름을 유지했으며 작동 리그나 애니메이션은 포함하지 않습니다. 부품 수가 많으므로 여러 대를 표시하거나 모바일에서 사용할 때는 용도에 맞는 추가 최적화가 필요할 수 있습니다.

## 구성

1. `01_Carrier`: 실제 축간 거리로 배치한 6축, 타이어 12개, 유리창·와이퍼·미러·등화류·그릴·계단.
2. `02_Outriggers`: 아웃리거 4개, 유압 잭, 지면 받침, 호스.
3. `03_Slewing_and_Ballast`: 선회 베어링과 받침, 낮은 후방 균형추, 마스트 전개 실린더.
4. `04_Telescopic_Mast`: 박스형 신축 마스트 3구간, 연결부, 사다리, 점검 패널.
5. `05_Operator_Cabin`: 마스트 중간 높이 조종실, 내부 좌석·콘솔, 접근 발판·난간.
6. `06_Jib_*`: 수평 격자 지브 5구간, 대각재·접힘 관절·핀·트롤리 레일.
7. `07_Guys_and_Head`: 상부 지지 프레임, 지브 지지재와 후방 지지재.
8. `08_Trolley_and_Hook`: 이동 트롤리, 수직 로프 2줄, 훅 블록과 열린 갈고리.
9. `90_Studio`, `91_Cameras`: 촬영용 바닥·조명·전체/차체/측면 카메라.

`SK1265_AT6_MODEL`을 이동하면 모델과 촬영 요소가 함께 이동합니다. 촬영 바닥은 별도입니다. 개별 부품은 이름과 컬렉션으로 찾아 편집할 수 있습니다. 별도 접힘 애니메이션이나 작동 리그는 포함하지 않았습니다.

## 도면을 반영한 부분과 추정한 부분

- 지브 중심선 최대 반경: **60m**.
- 지브 하부 주 구조 기준 높이: **37.2m**. 원형 강관 표면은 중심선보다 반지름만큼 아래로 내려갑니다.
- 축간 거리: **2.297 / 1.614 / 1.345 / 1.345 / 1.342m**.
- 아웃리거 받침 중심 간격: **7.95 × 7.66m**.
- 참고용 운송 전체 길이 16.279m는 접힌 장비의 돌출을 포함한 치수입니다. 본 모델은 전개 상태이므로 그 길이를 차체 자체의 길이로 사용하지 않았습니다.
- 격자 구간 길이 14/14/12/12/8m, 강관 지름, 신축 마스트의 각 구간 단면, 조종실 크기, 세부 유압·기계 구조는 사진을 바탕으로 한 시각적 추정입니다.

## 다시 생성

Blender 5.2.2 LTS에서 MCP로 생성하고 실제 렌더를 확인했습니다. `build_scene.py`와 나머지 모듈을 같은 폴더에 두고 아래와 같이 실행하면 새 장면을 만들어 같은 폴더에 저장합니다.

```sh
blender --background --python build_scene.py
```

기존 장면을 삭제하지 않습니다. 렌더 이미지는 저장된 카메라를 선택하여 생성할 수 있습니다. 이 모델은 외관 시각화용이며 세부 조립 설계 데이터는 아닙니다.

# EQ-001 중장비 접근 경보

## 1. 목적

위험 엔진이 감지한 중장비 접근 경보와 현재 검증 경로에 연결된 행동의 근거를 설명한다.

시뮬레이션 전용 합성 자료다. 실제 현장 사용 지침, 실제 승인·인증·법규 준수의 증거가 아니다. 위험·행동·경로·목적지는 서버 엔진이 결정하며 이 문서는 그 조건에 맞는 설명만 제공한다.

## 2. 적용 조건

SITE-CONSTRUCTION-01의 equipment 실행에서 위험 엔진이 작업자를 EQUIPMENT-A 접근 영향 대상으로 지정했을 때 적용한다. 경로 안내는 엔진이 유효한 경로와 목적지를 제공한 경우에만 포함한다.

검색 적용 시 siteIds, 요청 모드 또는 common, 위험 유형, 역할, 구역·물질·행동·프로필 조건, 유효기간을 모두 확인한다. 합성 문서는 독립 검토 기록과 approved_for_demo 상태가 확인된 데모 검색에서만 사용할 수 있다. draft, retired, 기한 전·만료 문서는 검색 근거에서 제외한다.

## 3. 적용 제외 조건

화재·가스 모드, 영향 대상으로 확인되지 않은 작업자, 위치 불명 또는 유효 경로가 없는 상황의 이동 설명에는 적용하지 않는다.

## 5. 행동 코드와 설명

- `ALERT_HAZARD`: 위험 엔진이 지정한 장비와 영향 구역의 접근 경보를 설명한다.
- `FOLLOW_VALIDATED_ROUTE`: 서버가 현재 유효하다고 판단한 경로만 설명한다. 문서가 경유지나 목적지를 추가하지 않는다.

현재 엔진의 actionCode와 일치하는 설명만 사용한다. 본문은 하나의 절차 검색 단위로 유지하여 적용 조건·행동·예외를 함께 확인한다.

## 6. 개인화 적용

경로 엔진에 전달된 확인된 stairsAllowed와 assistanceRequired를 설명에 연결한다. 동일 장비 상황에서도 개인 제약에 따라 경로가 다를 수 있다.

언어는 preferredLocale을 사용하고 국적으로 추정하지 않는다. 나이·성별에서 이동 능력이나 이해 능력을 추정하지 않으며 미입력 프로필을 제약 없음으로 취급하지 않는다.

## 7. 예외 및 기본 안내

경로 없음은 EQ-004, 위치 불명은 EQ-005의 조건을 적용한다. RAG 지연·실패에도 검토된 기본 경보와 서버 경로가 먼저 제공된다.

검색 근거 없음·충돌·모델 지연·실패·잘못된 인용·행동 불일치에는 보조 설명을 생략하고 검토된 기본 안내를 유지한다. 실제 경로·목적지·연결 관계·장비 제어·임계값을 생성하지 않는다.

## 10. 확인할 상태

- 위험 대상 작업자
- 유효 경로와 안내 버전
- 경보 수신·이해 여부

기기 수신 확인, 작업자의 이해 확인, 담당자의 지원 수락, 작업자 또는 엔진의 도착 확인은 각각 별도 상태이며 서로 자동 대체하지 않는다.

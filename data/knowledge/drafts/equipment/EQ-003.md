# EQ-003 개인 이동 제약을 반영한 회피 안내

## 1. 목적

계단 이용 불가로 확인된 작업자에게 경로 엔진이 선택한 회피 경로의 개인화 근거를 설명한다.

시뮬레이션 전용 합성 자료다. 실제 현장 사용 지침, 실제 승인·인증·법규 준수의 증거가 아니다. 위험·행동·경로·목적지는 서버 엔진이 결정하며 이 문서는 그 조건에 맞는 설명만 제공한다.

## 2. 적용 조건

equipment 실행에서 stairsAllowed가 확인된 false이고 해당 profileVersion으로 계산한 유효 경로가 있을 때 적용한다.

검색 적용 시 siteIds, 요청 모드 또는 common, 위험 유형, 역할, 구역·물질·행동·프로필 조건, 유효기간을 모두 확인한다. 합성 문서는 독립 검토 기록과 approved_for_demo 상태가 확인된 데모 검색에서만 사용할 수 있다. draft, retired, 기한 전·만료 문서는 검색 근거에서 제외한다.

## 3. 적용 제외 조건

계단 이용 여부 미입력·미확인, stairsAllowed true, 화재·가스 모드, 오래된 프로필 기반 경로, 경로 없음에는 이 이동 설명을 적용하지 않는다.

## 4. 필요한 입력 필드

- `siteId`
- `simulationType`
- `runId`
- `workerId`
- `actionCode`
- `guidanceId`
- `guidanceVersion`
- `profileVersion`
- `expiresAt`
- `stairsAllowed`
- `assistanceRequired`
- `profileConfirmedAt`
- `routeVersion`
- `routeStatus`
- `nextWaypointLabel`
- `destinationLabel`

필수 입력이 없으면 추측으로 채우지 않고 미확인 또는 설정 필요로 남긴다. 이름·생년월일·의료 진단명은 본 검색 절차의 입력이 아니다.

## 5. 행동 코드와 설명

- `FOLLOW_VALIDATED_ROUTE`: 확인된 계단 이용 불가 조건을 반영해 서버가 제공한 경로만 설명한다.
- `REQUEST_ASSISTANCE`: 확인된 보조 필요 또는 작업자의 요청을 별도 지원 흐름으로 전달한다.

현재 엔진의 actionCode와 일치하는 설명만 사용한다. 본문은 하나의 절차 검색 단위로 유지하여 적용 조건·행동·예외를 함께 확인한다.

## 6. 개인화 적용

나이·성별·국적에서 계단 이용 능력이나 이동 속도를 추정하지 않는다. 본 문서의 false 조건은 확인된 기능 제약이며 미입력 값과 다르다.

언어는 preferredLocale을 사용하고 국적으로 추정하지 않는다. 나이·성별에서 이동 능력이나 이해 능력을 추정하지 않으며 미입력 프로필을 제약 없음으로 취급하지 않는다.

## 7. 예외 및 기본 안내

맞는 경로를 찾지 못하면 EQ-004로 처리하고 계단 이용을 임의 허용하지 않는다. 보조가 필요해도 요청·배정·수락을 자동으로 동일 처리하지 않는다.

검색 근거 없음·충돌·모델 지연·실패·잘못된 인용·행동 불일치에는 보조 설명을 생략하고 검토된 기본 안내를 유지한다. 실제 경로·목적지·연결 관계·장비 제어·임계값을 생성하지 않는다.

## 9. 영어 안내 예시

## 10. 확인할 상태

- stairsAllowed false 확인
- 경로가 참조한 profileVersion
- 지원 요청·수락
- 현재 유효 경로

기기 수신 확인, 작업자의 이해 확인, 담당자의 지원 수락, 작업자 또는 엔진의 도착 확인은 각각 별도 상태이며 서로 자동 대체하지 않는다.

## Shared interfaces checked as source text

`makeStore`/`openStore` return database, repository, configuration, dbPath, real `session(actor)` and close; they do not create a SimulationRuntime. `save` stamps and sanitizes observations in the new evidence root. `latestRows` reads raw active runs, heads, snapshots, checkpoints, guidance, audit and receipt tables; it does not normalize their JSON. `checkpointTarget` extracts raw target fields without the production checkpoint schema. Runtime world, frozen source IDs, equipment-cleared state, closure owners, target maps and the already-present arrival-intent map are also compared with the stored checkpoint context. Preserving an existing intent map does not add floor/node metadata to its separate x/y target. Legacy arrival-intent migration and arrival behavior remain the core slice's scope.

Recovery/failure/CAS tests explicitly use real Date/performance when eventually run, so marker timestamps can be bracketed by actual UTC. Simulation time remains explicit and deterministic.

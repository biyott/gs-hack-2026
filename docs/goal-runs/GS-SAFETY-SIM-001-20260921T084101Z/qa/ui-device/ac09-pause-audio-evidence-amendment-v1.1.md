## Five separate evidence layers

| Layer | Exact required observation on assigned final candidate | Limit |
| --- | --- | --- |
| Coordinator decision | Accepted primary identity, cancellation trigger/time, old queue invalidation, current state and issued stop request; `(runId,workerId,guidanceId,primaryGuidanceVersion)` correlated | Proves application decision, not actual device output |
| Native/TTS callback | Utterance/request ID, generation/primary identity, start/stop/error/completion callback timing and acceptance/rejection reason | Callback presence proves a callback; absence proves only no recorded callback in that interval |
| Local visible state | App current status/action/route/replay controls before/during/after stop; locale and freshness; retained receipt/display and explicit current cancellation/unavailable state where represented | Semantic text can verify labels/state; it does not prove pixel hierarchy or audible cutoff |
| Server/admin current versus history | Raw last acknowledged voice event/time/lineage, current run/guide validity and displayed label semantics; immutable started/history entries and firstGuidance digests preserved | Last reported playing may remain historical. It must not be presented as confirmed current playback when current playback is unknown/paused/cancelled. Do not fabricate server cancellation or completion acknowledgement |
| Physical output | Actual audible initial phrase, interruption/cutoff, no old queued phrase/replay/overlap, expected ko/en or reviewed fallback, and distinct haptic observation | Needs local direct listening/witness or permitted local output recording. Callbacks, volume or UI alone cannot pass it |

No new `voice-cancelled` wire feature, field or enum is mandated. The final contract may truthfully separate last-reported speech history from current status using existing representation. An immutable past started event stays recorded; current display must communicate its actual semantics and uncertainty. A null completion timestamp is not proof that no sound was emitted. No old callback may overwrite new primary state, create a completion/understanding/arrival response, or cancel an unrelated current utterance.

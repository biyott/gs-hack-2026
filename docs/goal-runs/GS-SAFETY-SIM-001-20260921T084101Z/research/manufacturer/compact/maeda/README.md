아래는 M-C1 PDF 1쪽의 표와 도면을 함께 확인한 값이다. M-C2 PDF 2쪽도 동일 값을 싣지만 **동일 제조사의 재게시 성격**이므로 독립 제조사 근거로 세지 않는다.

제조사는 표의 5.170m를 `Lateral`로 적었지만, 평면도 치수선은 트랙·차체의 길이축과 평행하다. 따라서 원문 명칭과 도면상 방향을 둘 다 저장한다. 4.808m와 4.704m를 더해 길이를 만들지 않는다. 이들은 `outer dims`로 표기된 외곽 치수이며 **패드 중심 사이 거리로 쓰지 않는다**. 패드 크기, 지지점 중심 좌표, 선회 중심으로부터 각 지지점 오프셋은 이 CE PDF에서 치수로 제공되지 않았다.

## 정격 하중의 좁은 적용 범위

아래 표는 **M-C2 PDF 2쪽**, `Rated Total Load Chart (4falls)`, `Outrigger extended to maximum`, **12.485m Boom** 열에서 전사했다. 이 열 밖, MID/MIN 지지대, Searcher Hook, 다른 줄걸이, 주행 인양, 중간 반경 보간에 적용하지 않는다. 제조사는 총정격에 **훅 질량 30kg를 포함**하며 실제 하중에 따른 붐 처짐을 반영한 작업반경이라고 설명한다. 순수 적재물 질량으로 표시하지 않는다.

## 모델링/RAG에서 미확인으로 보존할 값

- 지지점 중심의 정확한 좌표, 패드의 길이·폭·면적, 설치 시 높이와 지면 경사 허용값.
- 도면 기준 선회 원점의 수치 오프셋, 붐 힌지 위치, 후방 선회반경, 3D CAD의 정밀 부품 형상.
- Searcher Hook 실제 길이·SH 오프셋 각도, 옵션별 전체 운송 외곽, 모든 부속 자세의 정격표.
- CE 기본 자료와 일본어 설명서의 **4.110m 대 4.145m** 차이 원인. 시장·장착품·개정 차이 가능성을 확정하지 않는다.
- 현물 일련번호와 이 판본의 일치, 실장 조건, 지내력, 풍속 제한, 현장 안전거리. 최대 작업반경을 보편적 위험반경으로 사용하지 않는다.

## 검증 기록

1. 공식 global 제품 페이지에서 모델 접미사 `-5` 및 PDF 제목을 확인했다.
2. M-C1 4쪽과 M-C2 2쪽을 로컬 PDF에서 렌더링해 직접 보았다. 텍스트 추출만으로 도면 축 방향을 추정하지 않았다.
3. 별도 읽기 전용 조사자가 M-C1 1쪽을 독립 렌더링해 운송 외곽, 세 방향 지지 외곽, 패드 중심 좌표 부재를 재확인했다.
4. 반대 검색에서 이전 `MC305C-3` 자료와 일본어 `MC305C-5` 설명서를 찾아 별도 식별했다. `-3` 자료는 CE `-5` 사실표에 편입하지 않았다.
5. 원본 파일 크기를 HTTP Content-Length와 대조하고 SHA256을 기록했다. 기계가 읽는 일부 수치는 `facts.json`에 보관한다.

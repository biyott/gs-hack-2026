이 문서는 CE 데이터의 대체값이 아니다. 같은 `MC305C-5` 명칭이라도 판본·기계 일련번호·치수 기준이 다른 자료를 섞지 않기 위한 반대 근거다.

## 원문 식별

- [제조사 공식 일본어 PDF](https://www.maesei.co.jp/download/docs/MC305C-5_manual.pdf), 총 **350 PDF쪽**.
- PDF 1쪽 표지: 문서번호 **103-OM2409-00**, 적용호기 **D5002 이후**. `이후`는 표지의 일련번호 적용 표기이며 이번에 조사하지 않은 다른 지역 모델 전체로 확장하지 않는다.
- PDF 349쪽 판권면: **초판 2024년 9월 30일**. 이 페이지는 인쇄 쪽번호 없음.
- PDF 메타데이터 생성 **2024-09-17 19:03:12 +09:00**, 수정 **2025-03-05 14:14:19 +09:00**. 메타데이터 수정일을 본문 개정일로 바꾸어 쓰지 않는다.

PDF 61쪽/인쇄 **3-5**, 도면 **EAM38740**은 MAX/MID/MIN 지지 전개의 상세 평면도다. 위에서 아래로 MAX/MID/MIN 차체 길이축 방향 **4,888 / 4,592 / 4,291mm**, 원문 앞쪽 폭 **4,504 / 4,110 / 3,712mm**, 뒤쪽 폭 **4,396 / 3,941 / 3,477mm**를 명시한다. 치수 연장선은 CE 외곽 끝점보다 발판 내부의 선/중심에 연결되는 것으로 보인다. 따라서 **패드 중심선 기준일 가능성이 높은 도면상 관찰**로 기록하며, 여기의 수치를 CE의 확정 지지점 좌표로 전용하지 않는다.

같은 PDF 61쪽은 도면에 30°/40° 다리 방향, 종방향 기준선 양측 **2,913/1,975mm(MAX)**, **2,782/1,810mm(MID)**, **2,648/1,643mm(MIN)**를 표기한다. 이 수치는 일본어 해당 도면에서 실제 확인한 값이다. 그 기준선이 CE 모델의 3D 원점·선회 원점과 같은지, 발판 센터의 정의가 동일한지 제조사 문서로 닫지 못했으므로 기본 JSON의 `supportCenters`는 계속 `null`이다.

PDF 62쪽/인쇄 **3-6**은 4줄 걸이 최대/중간 전개 하중표이고 PDF 63쪽/인쇄 **3-7**은 최소 전개 및 다음 2줄 걸이 구간을 포함한다. 기본 CE 묶음에는 **global brochure PDF 2쪽 하중표만 전사**했으며, 일본어 설명서의 다른 줄걸이·지원 조건을 끌어와 공백을 채우지 않았다.

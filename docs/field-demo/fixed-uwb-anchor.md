# Note20을 고정한 UWB 시연

EQUIPMENT 폰을 고정하고 작업자 폰만 움직이는 시연용 좌표 설정이다. 카메라나 마커 없이 EQUIPMENT에서 받은 실제 거리·방위각으로 작업자 **폰의 UWB 안테나 위치**를 계산한다. GPS나 이동하는 중장비의 절대 위치를 측정하는 기능은 아니다.

## 준비와 실행

1. 세 폰을 같은 서버에 연결하고 각각 `EQUIPMENT`, `WORKER_1`, `WORKER_2`로 선택한다. 이번 실기기 구성에서 EQUIPMENT는 `SM-N986N`(Note20 Ultra)이다. 컨트롤러가 방위각을 제공해야 한다.
2. Note20을 **세로로 세우고 뒷면을 작업자 활동 영역으로 향하게** 고정한다. Android UWB 방위각 0°는 폰 뒷면에서 수직으로 나가는 방향이다. 상단 모서리 방향이 아니다. [Android UWB 좌표계](https://android.googlesource.com/platform/frameworks/base/+/060a1ca3ffd1d1f36e0daca73f4bd510b8978a75/core/java/android/uwb/AngleOfArrivalMeasurement.java)
3. 관제의 카메라·UWB 추적 영역에서 고정 기준점을 적용한다. X/Y는 140×50cm 시연 테이블에서의 위치이고, 방향은 지도 오른쪽이 0°, 위쪽이 90°이다. 기본 입력은 왼쪽 중앙 `(0, 25)cm`, 방향 `0°`이며 **실제 배치에 맞춰 적용해야 한다**.
4. 높이는 같은 기준면에서 각 폰 안테나까지의 높이로 입력한다. 높이 기본값이 모두 0이면 세 안테나가 같은 높이라는 가정이다. 고도각이 수신되면 그 각도로 수평 거리를 계산하고, 고도각이 없을 때 입력한 높이 차이를 사용한다.
5. 위치 입력을 **장치 추적**으로 선택한다. 실행 준비 또는 실행 중 상태에서 세 폰의 앱을 전면에 유지한다. 일시정지·완료 상태에서는 앱이 측정을 중단하므로 다시 시연하려면 초기화한다.
6. 작업자 폰을 움직여 위치 관측의 실제 거리·방위각 및 좌표가 갱신되는지 확인한다. 테이블 1cm는 기존 시뮬레이터의 월드 1m로 표시된다.

## 표시와 제한

- 장비 위치는 사용자가 설정한 고정 좌표로 표시된다. 장비 자체 위치를 UWB로 실측한 것이 아니다.
- 작업자 좌표는 설정한 기준점·방향에 상대적인 실측값이다. Note20을 이동하거나 돌리면 기준점을 다시 설정해야 한다.
- 거리만 수신되면 위치를 만들지 않는다. 오래되거나 유효하지 않은 관측도 현재 위치로 표시하지 않는다.
- 실제 계산 좌표를 지도 안으로 강제로 옮기지 않는다. 지도에서 작업자가 사라지면 관측 좌표가 테이블 범위 밖인지, 기준 방향과 실제 배치가 일치하는지 확인한다.
- 기준점을 변경하거나 해제하면 이전 UWB 좌표가 무효화되고 다음 측정을 기다린다.
- 이 설정은 서버 메모리에 보관된다. **서버 재시작 후 다시 적용해야 한다.**

## API

관리자 또는 운영자는 `POST /api/tracking/uwb-anchor`에 `{ "anchor": ... }`를 보내 적용하고, `{ "anchor": null }`로 해제할 수 있다. 좌표·높이는 미터, 방향은 라디안이다. 응답은 추적 스냅샷이며 `uwbAnchor`에 현재 설정이 포함된다. 인증·동일 출처 검사와 입력 검증은 기존 추적 API와 동일하게 적용된다.

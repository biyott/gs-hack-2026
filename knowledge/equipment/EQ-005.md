# EQ-005 위치 수신 중단

## 1. 목적

작업자 위치 수신 중단·오래된 관측으로 현재 위치가 불명인 상태를 설명한다.

시뮬레이션 전용 합성 자료다. 실제 현장 사용 지침, 실제 승인·인증·법규 준수의 증거가 아니다. 위험·행동·경로·목적지는 서버 엔진이 결정하며 이 문서는 그 조건에 맞는 설명만 제공한다.

## 2. 적용 조건

equipment 실행에서 서버가 작업자 위치를 unknown 또는 stale로 판단하고 POSITION_UNKNOWN을 선택한 경우에 적용한다.

검색 적용 시 siteIds, 요청 모드 또는 common, 위험 유형, 역할, 구역·물질·행동·프로필 조건, 유효기간을 모두 확인한다. 합성 문서는 독립 검토 기록과 approved_for_demo 상태가 확인된 데모 검색에서만 사용할 수 있다. draft, retired, 기한 전·만료 문서는 검색 근거에서 제외한다.

## 3. 적용 제외 조건

최근 유효한 위치가 확인된 경우, 화재·가스 환경 센서 단절, 거리값만으로 2D 위치를 추정하는 설명에는 적용하지 않는다.

## 4. 필요한 입력 필드

- `siteId`
- `simulationType`
- `runId`
- `workerId`
- `actionCode`
- `guidanceId`
- `guidanceVersion`
- `profileVersion`
- `expiresAt`
- `positionStatus`
- `lastObservedAt`
- `positionSource`
- `routeVersion`
- `assistanceStatus`

필수 입력이 없으면 추측으로 채우지 않고 미확인 또는 설정 필요로 남긴다. 이름·생년월일·의료 진단명은 본 검색 절차의 입력이 아니다.

## 5. 행동 코드와 설명

- `POSITION_UNKNOWN`: 현재 위치를 확인할 수 없음을 설명한다. 마지막 위치를 현재 위치로 표현하지 않는다.
- `REQUEST_ASSISTANCE`: 필요한 지원 요청과 담당자 확인 절차를 제공한다.

현재 엔진의 actionCode와 일치하는 설명만 사용한다. 본문은 하나의 절차 검색 단위로 유지하여 적용 조건·행동·예외를 함께 확인한다.

## 6. 개인화 적용

기존에 확인된 프로필만 유지하며 위치 단절을 개인 이동 능력의 변화로 해석하지 않는다.

언어는 preferredLocale을 사용하고 국적으로 추정하지 않는다. 나이·성별에서 이동 능력이나 이해 능력을 추정하지 않으며 미입력 프로필을 제약 없음으로 취급하지 않는다.

## 7. 예외 및 기본 안내

마지막 좌표에서 임의의 새 경로를 생성하지 않는다. 단절·stale 판정 기준은 엔진 설정을 따르며 이 문서에 임계값을 만들지 않는다. 위치 복구 시 새 안내 버전을 확인한다.

검색 근거 없음·충돌·모델 지연·실패·잘못된 인용·행동 불일치에는 보조 설명을 생략하고 검토된 기본 안내를 유지한다. 실제 경로·목적지·연결 관계·장비 제어·임계값을 생성하지 않는다.

## 8. 한국어 안내 예시

> 안내 {guidanceVersion}: 현재 위치를 확인할 수 없습니다. 마지막 수신 위치를 현재 위치로 사용하지 마세요. 도움이 필요하면 요청해 주세요.

## 9. 영어 안내 예시

> Guidance {guidanceVersion}: your current position cannot be confirmed. Do not use the last received position as the current position. Request assistance if needed.

## 10. 확인할 상태

- 위치 unknown·stale 상태
- 관측 출처·마지막 관측 시각
- 복구 후 새 안내
- 지원 요청

기기 수신 확인, 작업자의 이해 확인, 담당자의 지원 수락, 작업자 또는 엔진의 도착 확인은 각각 별도 상태이며 서로 자동 대체하지 않는다.

# Noto Sans KR

The app bundles the unmodified Noto Sans KR variable TrueType font from the official [Google Fonts repository](https://github.com/google/fonts/tree/e44c4b011a820c2cbe2fd2cfa8052037d7edb571/ofl/notosanskr). The local filename is `NotoSansKR-Variable.ttf`; the upstream filename is `NotoSansKR[wght].ttf`.

- Source revision: `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`.
- Retrieved: 2026-09-21.
- Font source: [NotoSansKR[wght].ttf](https://raw.githubusercontent.com/google/fonts/e44c4b011a820c2cbe2fd2cfa8052037d7edb571/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf).
- License source: [OFL.txt](https://raw.githubusercontent.com/google/fonts/e44c4b011a820c2cbe2fd2cfa8052037d7edb571/ofl/notosanskr/OFL.txt).
- License: SIL Open Font License 1.1; its complete original text and copyright notice are in [OFL.txt](OFL.txt).
- Flutter family registration: `Noto Sans KR`. This matches `SafetyTypography.fontFamilyFallback` and is the bundled Korean/Latin fallback named in the root design contract.
- Variable axis: `wght`, 100–900. The design's 450, 550, and 650 weights are supported.

Both downloaded files were verified against the official GitHub content API's byte sizes and Git blob SHA-1 values. The font has a TrueType SFNT header and an `fvar` weight axis. Rendering and glyph checks belong to the app's visual QA.

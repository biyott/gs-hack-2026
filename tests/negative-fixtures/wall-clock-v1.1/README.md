# QR-004 문서 유효기간 시계 바인딩 v1.1

이 디렉터리는 [QA 시계 바인딩](../../../docs/goal-runs/GS-SAFETY-SIM-001-20260921T084101Z/qa/clock-binding-v1.1.md)에 따른 테스트 전용 파생 입력이다. 원본 26개 사례와 원본 부정 fixture는 수정하지 않았다. 시나리오 가상 시각 09:00은 유지하고, 파생 사례의 문서 유효기간 검사 시각만 UTC 09:30으로 분리한다.

원본 fixture 16개를 복사했다. `NEG-EXPIRED.expiresAt`만 09:00에서 09:30으로 옮겨 정확한 만료 경계를 유지하고 해당 합성 자료의 검토 내용 해시를 재계산했다. `NEG-FUTURE.effectiveFrom=2027-01-01`은 가상 시각에 상대적인 경계가 아니므로 그대로다. 나머지 원본 fixture 15개는 바이트가 동일하다. 실제 정상 지식의 승인·유효기간·검토 이력은 바꾸지 않았다.

`NEG-REVIEW-BOUNDARY`는 별도로 추가한 격리 fixture다. 검토 시각을 `2026-09-21T09:13:05.116Z`로 둔 합성 입력이며 1ms 전·정확한 시각·1ms 후의 필터 동작을 검사한다. 검토자는 명시적인 test-only 값이며 실제 승인 이력을 만들지 않는다.

[derivation-manifest.json](derivation-manifest.json)은 원본·파생 파일과 승인 ledger의 SHA-256, 변경 필드와 이유를 기록한다. [공용 로더](../../../src/server/rag/case-clock.ts)는 원본과 ledger 전제 조건 및 파생 내용 해시를 확인한다. 정상 색인에는 이 디렉터리를 넣지 않는다.

원본 09:00 실행에서 관찰한 no_match 결과는 과거 시점의 미승인 배제 결과다. 당시 도구 출력 외 별도 원시 결과 파일을 저장하지 못한 증거 공백을 manifest에 기록했다. 새 역사 시점 재실행은 별도 실행이며 과거 결과 파일의 복원이 아니다. mock 임베딩 결과는 실제 모델 성공 또는 독립 QA 수락 증거가 아니다.
